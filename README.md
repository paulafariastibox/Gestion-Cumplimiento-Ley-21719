# TIBOX · Gestión de Cumplimiento Ley N° 21.719

Prototipo web autocontenido para gestionar por empresa los documentos, evidencias y avance asociados a la Ley N° 21.719 de Protección de Datos Personales.

## Incluye

- 8 ámbitos de cumplimiento y 41 entregables.
- Empresas de demostración: TIBOX, Froens SpA, Quintero Energía y QC Terminales Chile.
- Cálculo automático de avance global y por ámbito.
- Estados: No iniciado, En proceso, Completado y No aplica.
- Responsable, fecha objetivo, última revisión, notas y evidencias por documento.
- Creación de nuevas empresas y exportación del avance en JSON.
- Persistencia local en el navegador mediante `localStorage`.
- Diseño responsive con identidad visual TIBOX.

## Uso

Abre `index.html` directamente en el navegador o publícalo con GitHub Pages. No requiere instalación ni proceso de compilación.

## Alcance del prototipo

Los archivos seleccionados como evidencias no se suben a un servidor: el prototipo conserva únicamente su nombre. Para producción se debe incorporar autenticación, base de datos, almacenamiento seguro, control de acceso, auditoría y respaldo.
